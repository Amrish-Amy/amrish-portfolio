# Amrish Portfolio

A personal portfolio application built with React and Vite.

## Prerequisites

Install the following software before running the application:

- [Node.js](https://nodejs.org/) 18 or later
- npm (included with Node.js)
- [Git](https://git-scm.com/)

Confirm that Node.js and npm are installed:

```bash
node --version
npm --version
```

## Installation

1. Clone the repository:

	```bash
	git clone <repository-url>
	```

2. Enter the project directory:

	```bash
	cd amrish-portfolio
	```

3. Install the project dependencies:

	```bash
	npm install
	```

## Run Locally

Start the Vite development server:

```bash
npm run dev
```

Open the URL displayed in the terminal, usually <http://localhost:5173>.

## Production Build

Create an optimized production build:

```bash
npm run build
```

The generated files are written to the `dist` directory.

Preview the production build locally:

```bash
npm run preview
```

## Linting

Run ESLint across the project:

```bash
npm run lint
```
